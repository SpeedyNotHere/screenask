/>[window_name] > instantly maximizes and puts this app in the foreground , make sure you type the window name correctly. not case sensitive, and you dont have to write the full name (eg. if a window is called "i love cats" , "/>i" would work fine if there are no other windows that start with "i")

/run [cmd] > (not working as intended rn) opens a run dialog and enters parameter

/ask [question] > useless af, but its there if you need it (asks ai a question)

/sys > opens windows settings

/ps [cmd] > (not working as intended rn) opens powershell and runs a command

/music [play music] [pause music] > does what it says

/help > help for command list
